# 🧬 DNA Toolkit — Bioinformatics Project

A beginner bioinformatics toolkit built with Python and BioPython.
Analyzes DNA sequences like real lab software!

## 🔬 Features
- Count nucleotides (A, T, G, C)
- Calculate GC Content percentage
- Transcribe DNA to RNA
- Translate RNA to Protein
- Generate Reverse Complement

## 🛠 Installation
pip install biopython

## 🚀 Usage
python dna_toolkit.py

## 📊 Example Output
- DNA Sequence : ATGCGATACGCTTCGAT...
- GC Content   : 50.98% ✅ Normal
- RNA          : AUGCGAUACGCUUCGAU...
- Protein      : MRYASIDRS*
- Reverse Comp : CGATCGATCGATGCTAG...
